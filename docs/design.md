# 《一箭又一箭》需求分析与设计

## 1. 项目目标

使用 Python 和 Pygame 开发一个点击式箭头解谜游戏。

玩家点击棋盘中的箭头。如果箭头前进方向上没有其他箭头，箭头就飞出棋盘并消失；如果存在其他箭头，则显示碰撞反馈，并扣除一次失误机会。

游戏至少包含三个可以正常通关的关卡。

## 2. 主要功能

游戏需要实现：

1. 开始界面、游戏界面、通关界面和失败界面；
2. 显示上、下、左、右四种箭头；
3. 使用鼠标点击箭头；
4. 判断箭头前进方向上是否存在阻挡；
5. 无阻挡时播放飞出动画并消除箭头；
6. 有阻挡时播放碰撞反馈并扣除失误次数；
7. 显示当前关卡、剩余箭头和剩余失误次数；
8. 清空箭头后进入下一关；
9. 失误次数耗尽后显示失败；
10. 支持重新开始当前关卡。

## 3. 数据表示

每个箭头保存行号、列号和方向：

```python
Arrow(row=1, col=2, direction="right")
```

四个方向使用以下字符串表示：

```python
"up"
"down"
"left"
"right"
```

每个关卡使用一个列表保存所有箭头，例如：

```python
[
    (0, 0, "right"),
    (0, 3, "up"),
    (2, 1, "left"),
]
```

## 4. 路径判断方法

点击箭头后，从箭头前方的第一个格子开始，沿箭头方向逐格检查：

- 向上：行号不断减一；
- 向下：行号不断加一；
- 向左：列号不断减一；
- 向右：列号不断加一。

如果检查到其他箭头，则路径被阻挡。

如果一直检查到棋盘边界都没有发现其他箭头，则路径畅通，箭头可以飞出。

## 5. 游戏状态

游戏包含以下状态：

```text
START        开始界面
PLAYING      游戏进行中
LEVEL_CLEAR  当前关卡通关
GAME_OVER    当前关卡失败
ALL_CLEAR    全部关卡通关
```

## 6. 代码结构

```text
se_onearrowgame/
├── main.py
├── game.py
├── arrow.py
├── levels.py
├── ui.py
├── assets/
├── tests/
├── docs/
│   └── design.md
├── README.md
└── requirements.txt
```

各文件的作用：

- `main.py`：程序入口和 Pygame 主循环；
- `game.py`：游戏状态、点击处理和关卡流程；
- `arrow.py`：箭头数据和路径判断；
- `levels.py`：保存三个关卡的数据；
- `ui.py`：绘制界面、棋盘、箭头和按钮；
- `tests/`：保存自动化测试。

## 7. 开发顺序

1. 创建游戏窗口和开始界面；
2. 绘制棋盘和四种箭头；
3. 实现鼠标点击和路径判断；
4. 实现飞出动画和碰撞反馈；
5. 实现失误、失败和重新开始；
6. 设计并试玩三个关卡；
7. 实现通关和关卡切换；
8. 完成测试、README 和游戏截图。

## 8. 测试计划

重点测试以下内容：

- 无阻挡箭头能够消失；
- 被阻挡箭头不能消失，并扣除一次失误；
- 边缘箭头不会引发越界错误；
- 清空箭头后能够通关；
- 失误耗尽后显示失败；
- 重新开始后恢复初始布局和失误次数。
